# Templates de code pour Yobhou

Ce dossier contient des templates de code réutilisables pour le projet Yobhou.

## Templates disponibles

### Backend (Django)
- `models.py.template` : Template pour les modèles Django
- `serializers.py.template` : Template pour les sérialiseurs DRF
- `views.py.template` : Template pour les vues
- `urls.py.template` : Template pour les routes

### Mobile (Flutter)
- `model.dart.template` : Template pour les modèles Dart
- `service.dart.template` : Template pour les services API
- `page.dart.template` : Template pour les pages d'interface

## Utilisation

Pour utiliser un template :

```bash
cp template_name.py /path/to/destination
```

## Conventions

- Utiliser des templates pour les structures répétitives
- Adapter les templates aux spécificités de chaque app
- Documenter les variations possibles dans ce fichier
